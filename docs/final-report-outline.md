# SE2030 Final Report Checklist

1. Cover: title, module, group, member names/IDs and date.
2. Executive summary and problem statement.
3. Requirements and scope; include `requirements-traceability.md`.
4. Project management: sprints, task allocation, meetings and Git evidence.
5. Design: architecture, use-case, class, activity and ER diagrams.
6. Implementation: layers, MySQL/Flyway, security and six member modules.
7. UI: labelled customer, staff and admin screenshots.
8. Testing: automated results, manual scenarios and defect/fix evidence.
9. Security, privacy and ethics.
10. Limitations and simulated integrations.
11. Individual reflection for every member.
12. Conclusion, references and appendices.

Use dummy data in screenshots and remove credentials, full card numbers, PINs, identity values and private machine paths.
